# 🛠️ Portafolio de Laboratorios Técnicos - Soporte TI & Redes
¡Bienvenido a mi repositorio de documentación técnica! Este espacio está diseñado para demostrar mis habilidades prácticas y la aplicación de lógica estructurada en la resolución de incidentes de Microinformática, Operaciones de Red (NOC) y Mesa de Ayuda (Helpdesk).

La estructura de este repositorio se organiza mediante **Ramas (Branches)** independientes para cada módulo de estudio, garantizando un control de versiones limpio y profesional.

---

## 📂 Índice de Ramas y Especialidades

Para ver la documentación completa y las evidencias de cada laboratorio, selecciona la rama correspondiente en el menú desplegable de GitHub:

* 🌿 **Rama: `lab-01-redes`** -> Conectividad y Diagnóstico de Redes (`ipconfig`, pruebas ICMP, interpretación de latencia, bucles y lógica de saltos TTL).
* 🌿 **Rama: `lab-02-outlook`** -> Soporte de Microinformática (Resolución de errores de perfiles congelados `.OST`, archivado local `.PST` y gestión de sesiones de Microsoft 365).
* 🌿 **Rama: `lab-03-active-directory`** -> Gestión de Identidades y Accesos (Desbloqueo de cuentas, creación de usuarios y baja de personal en Active Directory).
* 🌿 **Rama: `lab-04-gestion-tickets`** -> Gestión de Incidentes e ITIL (Clasificación de impacto y urgencia, administración de colas en Jira/ServiceNow y cumplimiento de SLAs corporativos).
- 🌿 **Rama: `lab-05-diagnostico-noc`** -> Herramientas de Diagnóstico de Redes Avanzadas para el NOC (Análisis de saltos internacionales mediante `tracert`, cálculo e interpretación de latencia WAN y gobernanza ICMP).
